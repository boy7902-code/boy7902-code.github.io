# 🏡 우리 가족 대시보드

태블릿(가로·세로)에서 앱처럼 쓰는 가족 대시보드입니다. 날씨·일정·가족 미션(포인트)·손글씨 편지·장보기·집안 위키·가계부를 한 화면에 모았습니다.

- 주소: **https://boy7902-code.github.io/**
- 설치·빌드 도구 없이 순수 정적 파일(HTML/CSS/JS)로만 동작합니다.

## 무엇이 들어 있나

| 카드 | 기능 |
| --- | --- |
| 상단 | 실시간 시계(날짜·요일), 야간/절전 모드, 오늘 기온·날씨 아이콘·최고/최저·일교차·강수확률·미세먼지(PM10)·초미세먼지(PM2.5)·체감온도 |
| 오늘 · 이번 주 일정 | 오늘 일정과 다가오는 일정, 7일 주간 스트립(날짜를 누르면 그 날짜로 일정 추가), 완료 체크·수정·삭제 |
| 가족 미션 & 칭찬 포인트 | 구성원별 미션(+P), 미션마다 목표 시간(HH:MM)과 시간 내 완료 보너스(+P), 목표 시간 카운트다운 표시, 완료 시 실제 완료 시각과 '목표 시간 달성/초과' 배지, 오늘 완료 이력, 구성원별 오늘 완료 수·오늘 포인트·누적 포인트, 누적 포인트에 따라 진화하는 포켓몬 파트너(피카츄·파이리·꼬부기·이상해씨 4단계 진화, 언제든 파트너 변경), 레벨업 축하 효과 |
| 손글씨 & 스티커 편지함 | 손가락·펜으로 그리는 캔버스(펜 색 6종·굵기 3단계·지우개·되돌리기), 이모지 스티커 도장, '편지함에 보내기'로 이미지 카드 저장·크게 보기·다운로드 |
| 장보기 & 냉장고 메모 | 장보기/냉장고 탭, 추가·구매 완료 체크·삭제 |
| 타이머 & 음악 | 5~60분 프리셋 타이머(진행 링, 종료 알림음), 가족 플레이리스트·유튜브 링크 바로가기 |
| 우리 집 위키 | 생신·기념일 / 예방접종 / 집안 메모 / 연락처·와이파이 항목 추가·수정·삭제 |
| 이번 달 가계부 | 목표 예산·고정비·변동비 입력, 남은 예산과 사용률 게이지 |
| 설정(⚙️) | 날씨 위치(현재 위치·도시 검색·위도/경도 직접 입력), 파트너 포켓몬 선택, 구성원 이름, 밝게/어둡게, 절전 모드, 백업 내보내기·불러오기, 모두 지우기 |

## 쓰는 법

1. 태블릿 크롬에서 위 주소를 엽니다.
2. 오른쪽 위 ⋮ → **홈 화면에 추가**(또는 '앱 설치')를 누르면 주소창 없는 전체 화면 앱으로 열립니다.
3. 처음 열면 위치 사용을 한 번 물어봅니다. **허용**하면 우리 동네 날씨가 나오고, 나중에는 ⚙️ 설정 → 날씨 위치에서 동네 이름으로 바꿀 수 있습니다.
4. 모든 기록은 그 기기의 브라우저 저장소(localStorage)에 자동 저장됩니다. 기기를 바꿀 때는 ⚙️ 설정 → **백업 내보내기**로 JSON 파일을 받아 두고, 새 기기에서 **백업 불러오기**로 복원하세요.
5. 미션마다 목표 시간과 보너스 포인트를 정해 두면, 아이가 목표 시간 안에 끝냈는지 자동으로 확인해 보너스를 더해 줍니다. 결과는 미션 카드와 **오늘 완료 이력**에 완료 시각으로 남습니다.
6. 캐릭터는 포켓몬 파트너입니다. 누적 포인트 0/30/90/200P에서 4단계로 진화하며, 아이가 좋아하는 계열(피카츄·파이리·꼬부기·이상해씨)은 **🐾 파트너** 버튼이나 ⚙️ 설정에서 언제든 바꿀 수 있습니다.

## 개인정보

- 저장소에는 **어떤 개인정보도 들어 있지 않습니다.** 이름·주소·전화번호·실제 일정·실제 가계부 금액은 코드에 하드코딩되어 있지 않고, 기본값은 모두 중립적인 예시입니다.
- 사용자가 입력한 내용은 그 기기의 브라우저에만 저장되며 서버로 전송되지 않습니다. 저장소를 내려받은 사람도 다른 사람의 기록을 볼 수 없습니다.
- 네트워크로 나가는 것은 날씨 조회(Open-Meteo)와 포켓몬 그림(PokeAPI 이미지 저장소, `raw.githubusercontent.com`)뿐입니다. 위치 좌표는 날씨를 받아오는 데만 쓰입니다.
- 포켓몬 그림은 [PokeAPI/sprites](https://github.com/PokeAPI/sprites)의 공식 일러스트(official-artwork)를 불러오며, 그림을 못 받아오면 로컬에서 만든 SVG로 자동 대체됩니다.

## 사용한 무료 서비스

- [Open-Meteo](https://open-meteo.com/) — 날씨 예보 API (`api.open-meteo.com`)
- [Open-Meteo Air Quality](https://open-meteo.com/en/docs/air-quality-api) — 미세먼지 API (`air-quality-api.open-meteo.com`)
- [Open-Meteo Geocoding](https://open-meteo.com/en/docs/geocoding-api) — 동네 이름 검색 (`geocoding-api.open-meteo.com`)

모두 API 키 없이 쓸 수 있는 무료 서비스이며, 개인 사용 범위에서 호출합니다.

## 파일 구성

```
index.html            화면 뼈대
style.css             스타일(라이트/다크 테마, 태블릿·세로 반응형)
app.js                모든 동작(상태 저장, 날씨, 포켓몬 진화·목표 시간 미션, 캔버스, 타이머 등)
manifest.webmanifest  홈 화면에 추가할 때 쓰는 앱 정보
icons/                앱 아이콘(192·512·maskable PNG, SVG)
```
