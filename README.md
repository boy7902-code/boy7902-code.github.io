# 🏡 우리 가족 대시보드

태블릿(가로·세로)에서 앱처럼 쓰는 가족 대시보드입니다. 날씨·일정·가족 미션(아이 포인트)·포인트 사용·포켓몬 도감·손글씨 편지·장보기·집안 위키를 한 화면에 모았습니다.

- 주소: **https://boy7902-code.github.io/**
- 설치·빌드 도구 없이 순수 정적 파일(HTML/CSS/JS)로만 동작합니다.

## 쓰는 법

1. 태블릿 크롬에서 위 주소를 엽니다.
2. 오른쪽 위 ⋮ → **홈 화면에 추가**(또는 '앱 설치')를 누르면 주소창 없는 전체 화면 앱으로 열립니다.
3. 처음 열면 위치 사용을 한 번 물어봅니다. **허용**하면 우리 동네 날씨가 나오고, 나중에는 ⚙️ 설정 → 날씨 위치에서 동네 이름으로 바꿀 수 있습니다.
4. 모든 기록은 그 기기의 브라우저 저장소(localStorage)에 자동 저장됩니다. 기기를 바꿀 때는 ⚙️ 설정 → **백업 내보내기**로 JSON 파일을 받아 두고, 새 기기에서 **백업 불러오기**로 복원하세요.
5. 미션마다 목표 시간과 보너스 포인트를 정해 두면, 아이가 목표 시간 안에 끝냈는지 자동으로 확인해 보너스를 더해 줍니다. 결과는 미션 카드와 **오늘 완료 이력**에 완료 시각으로 남습니다.
6. **📅 월간·연간 달성** — 미션 패널의 이 버튼을 누르면 월간 달력과 연간 12개월 요약이 열립니다. 상단에서 **월간/연간**을 바꾸고, ‹ ›로 이전·다음 달(해)로 이동하며, 구성원(전체·성인 1·성인 2·아이)별로 걸러 볼 수 있습니다. 달력에서 **날짜를 누르면** 그날 완료한 미션의 완료 시각·목표 달성 배지·획득 포인트가 아래에 나오고, 연간 보기에서 **월 카드를 누르면** 그 달의 월간 달력으로 바로 이동합니다. 완료 이력은 최근 **400일(1년 이상)**까지 보관되어 1년 흐름을 그대로 되돌아볼 수 있습니다.
7. 캐릭터는 포켓몬 파트너입니다. **아이('아이' 구성원, id `m3`)가 미션을 끝낼 때만** 현재 파트너 경험치·누적 경험치·사용 가능 포인트가 함께 오르고, 성인 미션은 성인 통계에만 쌓입니다. 미션 체크를 취소했을 때만 되돌아갑니다.
8. **🎁 포인트 사용** — 부모가 아이에게 물건·보상을 사줄 때 내용(예: 포켓몬 카드 팩)과 사용 포인트(예: 50P)를 적으면 **사용 가능 포인트(잔액)만** 줄어듭니다. 포켓몬 경험치와 진화 단계는 절대 풀리지 않고, 사용 내역이 날짜·내용·차감 P로 남습니다.
9. **🏆 도감 · ✨ 새 포켓몬 입양** — 현재 파트너가 200P(최종 진화)에 도달하면 그 포켓몬이 도감에 영구 저장되고, '✨ 새 포켓몬 입양하기' 버튼이 열립니다. 새 파트너는 현재 파트너 경험치만 0P부터 다시 시작하고, **누적 경험치와 사용 가능 포인트는 그대로** 유지됩니다. 계열은 **🐾 파트너** 버튼이나 ⚙️ 설정에서 바꿀 수 있습니다.
10. **☁️ 가족 실시간 동기화** — 거실 태블릿과 폰이 같은 기록을 봅니다.
   - ⚙️ 설정 → **☁️ 가족 실시간 동기화**에 **동기화 주소**(`https://script.google.com/macros/s/…/exec`)와 **가족 PIN**을 한 번만 넣으면, 그 기기에서는 계속 자동으로 맞춰집니다. 주소와 PIN은 그 기기의 브라우저에만 저장됩니다.
   - 미션 체크·일정 추가·손글씨 편지처럼 무엇이든 바뀌면 1.5초 뒤 서버로 올라가고, 다른 기기는 30초 안에(또는 그 창을 다시 열 때) 같은 화면이 됩니다.
   - 변경분만 주고받고 서버가 합쳐 주기 때문에, 두 기기에서 동시에 체크해도 서로의 기록이 사라지지 않습니다.
   - 연결할 때 서버에 이미 기록이 있으면 **가져오기 / 이 기기 기록 올리기** 중에서 고를 수 있습니다.
   - 연결을 끊어도(연결 해제) 이 기기의 기록은 그대로 남습니다.
11. 저장 형식은 `v3`입니다. 이전 `v2` 데이터가 있는 브라우저에서는 아이 누적 포인트를 현재 파트너 경험치로 옮겨 안전하게 마이그레이션됩니다.

## 개인정보

- 저장소에는 **어떤 개인정보도 들어 있지 않습니다.** 이름·주소·전화번호·실제 일정·실제 금액은 코드에 하드코딩되어 있지 않고, 기본값은 모두 중립적인 예시입니다.
- 기본은 **이 기기의 브라우저에만** 저장되며 서버로 전송되지 않습니다. 저장소를 내려받은 사람도 다른 사람의 기록을 볼 수 없습니다.
- **☁️ 동기화를 직접 켠 경우에만**, 사용자가 지정한 본인의 비공개 Google 스프레드시트(Apps Script 웹 앱)로 기록이 전송됩니다. 주소와 가족 PIN은 공개 저장소 코드에 없고, 각 기기 브라우저에만 저장되며, 서버는 PIN이 맞을 때만 읽기/쓰기를 허용합니다.
- 동기화에 쓰는 Google 시트는 **비공개**이며, 웹 앱 주소를 아는 사람이라도 PIN을 모르면 아무 데이터도 받을 수 없습니다.
- 네트워크로 나가는 것은 날씨 조회(Open-Meteo)와 포켓몬 그림(PokeAPI 이미지 저장소, `raw.githubusercontent.com`)뿐입니다. 위치 좌표는 날씨를 받아오는 데만 쓰입니다.
- 포켓몬 그림은 [PokeAPI/sprites](https://github.com/PokeAPI/sprites)의 공식 일러스트(official-artwork)를 불러오며, 그림을 못 받아오면 로컬에서 만든 SVG로 자동 대체됩니다.

## 사용한 무료 서비스

- [Open-Meteo](https://open-meteo.com/) — 날씨 예보 API (`api.open-meteo.com`)
- [Open-Meteo Air Quality](https://open-meteo.com/en/docs/air-quality-api) — 미세먼지 API (`air-quality-api.open-meteo.com`)
- [Open-Meteo Geocoding](https://open-meteo.com/en/docs/geocoding-api) — 동네 이름 검색 (`geocoding-api.open-meteo.com`)

모두 API 키 없이 쓸 수 있는 무료 서비스이며, 개인 사용 범위에서 호출합니다.

```
index.html            화면 뼈대
style.css             스타일(라이트/다크 테마, 태블릿·세로 반응형)

icons/                앱 아이콘(192·512·maskable PNG, SVG)

```
