# 🏡 우리 가족 대시보드

태블릿(가로·세로)에서 앱처럼 쓰는 가족 대시보드입니다. 날씨·일정·아이 미션·포인트·포켓몬 도감·손글씨 편지·사고 싶은 것(위시리스트)·장보기·집안 위키를 한 화면에 모았고, **🔒 부모 모드(4자리 PIN)** 로 아이가 건드리면 안 되는 부분을 잠급니다.

- 주소: **https://boy7902-code.github.io/**
- 설치·빌드 도구 없이 순수 정적 파일(HTML/CSS/JS)로만 동작합니다.

## 화면 구성

화면 위쪽에 세 탭이 있습니다 — **🏠 대시보드 · ✏️ 손글씨 편지(새 편지 배지) · 🐾 포켓몬 놀이방**.

- **대시보드(태블릿 가로 1280×800)**: 2열 한 화면 — 왼쪽 열에 **가족 일정(2주 기본 · 1달/오늘 전환, 구글 캘린더 포함) · 오늘 학교 · 타이머**, 오른쪽 열에 **아이 미션(📖 151 도감 · 진화 경험치/선물 코인 · 오늘 끝낸 미션 접힘 줄) · 사고 싶은 것(🎤 · 🎁/🛒/🧊)**. 페이지 세로 스크롤은 0이고, 넘치는 내용은 각 카드 안에서만 굴러갑니다.
- **폰(390×844)**: 같은 카드가 1열로 쌓이고 가로 스크롤이 생기지 않습니다.
- **손글씨 편지 탭**: 편지 캔버스·도구·보내기·편지함이 한 화면에 크게 열립니다. 새 편지는 탭의 숫자 배지로 알려 줍니다.
- **포켓몬 놀이방 탭**: 도감에 모은 친구들이 풀밭에서 걸어 다니고, 콕 누르면 점프하며 좋아합니다.

## 쓰는 법

1. 태블릿 크롬에서 위 주소를 엽니다.
2. 오른쪽 위 ⋮ → **홈 화면에 추가**(또는 '앱 설치')를 누르면 주소창 없는 전체 화면 앱으로 열립니다.
3. 처음 열면 위치 사용을 한 번 물어봅니다. **허용**하면 우리 동네 날씨가 나오고, 나중에는 ⚙️ 설정 → 날씨 위치에서 동네 이름으로 바꿀 수 있습니다.
4. 모든 기록은 그 기기의 브라우저 저장소(localStorage)에 자동 저장됩니다. 기기를 바꿀 때는 ⚙️ 설정 → **백업 내보내기**로 JSON 파일을 받아 두고, 새 기기에서 **백업 불러오기**로 복원하세요.
5. 미션마다 **언제 하는 미션인지**를 정할 수 있습니다. 추가·수정 창의 **매일 / 평일(월~금) / 주말(토·일)** 칩을 누르거나 **월~일 버튼**을 하나씩 눌러 요일을 고르면, **오늘 요일에 해당하는 미션만** 오늘 미션 목록에 나옵니다. 카드에는 `매일`·`월~금` 같은 요일 배지가 붙고, 오늘 쉬는 미션은 목록 아래 **😴 오늘은 ○요일이라 쉬는 미션**에 접혀 있어 아이가 오늘 할 것만 보게 됩니다. 요일을 정하지 않은 예전 미션은 그대로 '매일'로 동작합니다.
   - **🎉 토요일은 '아이' 구성원의 자유의 날(숙제 없음)** — 토요일이 되면 **오늘 미션** 카드에 `🎉 오늘은 ○○ 자유의 날! 숙제가 없어요` 배너가 자동으로 뜨고, 일요일이 되면 저절로 사라집니다. 미션·완료·점수 기록은 이 안내 때문에 삭제되지 않습니다. 이름은 ⚙️ 설정의 구성원 이름(id `m3`)을 그대로 읽어 씁니다(기본값 '아이').
6. 마감 시간이 있는 미션은 5~9분 일찍 끝내면 +1P, 10분 이상 일찍 끝내면 +2P(총점)를 기본 포인트와 별도로 기록합니다. 마감 4분 전부터 마감 시각·마감 후 완료는 기본 포인트만 받아요. 미션별로 설정했던 예전 마감 보너스는 적용하지 않고, 과거 완료 이력의 점수는 다시 계산하지 않습니다.
7. **📅 월간·연간 달성** — 미션 패널의 이 버튼을 누르면 월간 달력과 연간 12개월 요약이 열립니다. 상단에서 **월간/연간**을 바꾸고, ‹ ›로 이전·다음 달(해)로 이동하며, 구성원(전체·성인 1·성인 2·아이)별로 걸러 볼 수 있습니다. 달력에서 **날짜를 누르면** 그날 완료한 미션의 완료 시각·조기 보너스 배지·획득 포인트가 아래에 나오고, 연간 보기에서 **월 카드를 누르면** 그 달의 월간 달력으로 바로 이동합니다. 완료 이력은 최근 **400일(1년 이상)**까지 보관되어 1년 흐름을 그대로 되돌아볼 수 있습니다.
8. 캐릭터는 포켓몬 파트너입니다. **아이('아이' 구성원, id `m3`)가 미션을 끝낼 때만** 현재 파트너 경험치·누적 경험치·사용 가능 포인트가 함께 오르고, 성인 미션은 성인 통계에만 쌓입니다. 미션 체크를 취소했을 때만 되돌아갑니다.
9. **🎁 포인트 사용** — 부모가 아이에게 물건·보상을 사줄 때 내용(예: 포켓몬 카드 팩)과 사용 포인트(예: 50P)를 적으면 **사용 가능 포인트(잔액)만** 줄어듭니다. 포켓몬 경험치와 진화 단계는 절대 풀리지 않고, 사용 내역이 날짜·내용·차감 P로 남습니다.
10. **🏆 도감 · ✨ 새 포켓몬 입양** — 현재 파트너가 200P(최종 진화)에 도달하면 그 포켓몬이 도감에 영구 저장되고, '✨ 새 포켓몬 입양하기' 버튼이 열립니다. 새 파트너는 현재 파트너 경험치만 0P부터 다시 시작하고, **누적 경험치와 사용 가능 포인트는 그대로** 유지됩니다. 계열은 **🐾 파트너** 버튼이나 ⚙️ 설정에서 바꿀 수 있습니다.
11. **☁️ 가족 실시간 동기화** — 거실 태블릿과 폰이 같은 기록을 봅니다.
   - ⚙️ 설정 → **☁️ 가족 실시간 동기화**에서 Google 계정으로 로그인합니다. 가족 기록은 Firebase Authentication과 Cloud Firestore를 통해 동기화됩니다.
   - 계정은 서버 Custom Claims의 `role: parent` 또는 `role: child` 권한이 있어야 합니다. Google 로그인만으로 가족 권한이 생기지는 않으며, 권한 없는 계정은 기록을 읽지 못합니다.
   - 보호자는 전체 기록을 관리하고 물건·보상에 쓸 포인트를 정산합니다. 미션·도장 획득 포인트는 완료기록에서 자동 반영됩니다. 아이 계정은 오늘 미션·장보기·편지 등 허용된 항목만 다룹니다.
   - 로그아웃 상태에서는 이 기기의 localStorage만 사용합니다. 예전 Apps Script 주소/PIN은 자동 연결·복원하지 않으며, 저장된 값이 있으면 설정의 **예전 Apps Script 연결 정보 → 이 기기의 저장 정보 지우기**로 지울 수 있습니다. 기존 기록은 자동 이관하지 않습니다.
12. **🔒 부모 모드** — 화면 위 **🔒 부모 모드 (잠김)** 이 기본입니다. 잠긴 동안 아이는 **미션 체크 · 포켓몬 도감 · 손글씨 편지 보내기 · 사고 싶은 것 적기 · 타이머 · 월간·연간 달성 보기**를 그대로 쓸 수 있습니다.
   - **미션 추가·수정·삭제, 포인트 사용(선물 사주기)·사용 내역 삭제·포인트 초기화, 일정 추가·수정·삭제, 장보기·위키 편집·삭제, 편지 삭제, 사고 싶은 것 삭제·필요 포인트 설정, ⚙️ 설정, 백업 내보내기·불러오기**는 4자리 PIN을 넣어야 열립니다.
   - PIN을 넣으면 **🔓 부모 모드**가 되고 **5분 뒤 자동으로 잠깁니다.** 바로 잠그려면 🔓 버튼을 한 번 누르면 됩니다.
   - PIN은 공개 코드에 들어 있지 않습니다. 기본값은 `0000`이고, 로그인 상태에서 바꾸면 보호자만 읽고 쓸 수 있는 비공개 Firestore 문서를 통해 보호자 기기끼리 동기화됩니다. 로그아웃 상태에서는 이 기기에만 저장됩니다. PIN 변경 뒤에는 이 기기의 부모 모드가 바로 잠깁니다.
   - PIN을 3번 틀리면 그 자리에서 멈춥니다.
13. **🖼️ 대기화면** — 상단의 **🖼️ 대기화면**을 누르면 화면 전체가 거실 디지털 액자가 됩니다. 큰 실시간 시계·날짜, 오늘 날씨와 미세먼지, 오늘 아이 미션 달성률·선물 코인, 그리고 화면 가득 살아 움직이는 파트너 포켓몬이 나옵니다(포켓몬을 누르면 하트가 터지며 대답해요). 오른쪽 위 **🏠 홈으로** 또는 ESC로 바로 돌아옵니다.
14. **📖 151 도감** — 포켓몬 카드의 **📖 151 도감**을 누르면 1세대 151종 전체를 번호순으로 볼 수 있습니다. 아직 만나지 못한 친구는 실루엣으로 보이고, 칸을 누르면 이름·타입·만난 날짜·진화 단계와 기준 포인트가 나오며 그 자리에서 그 계열을 파트너로 고를 수 있습니다. 지나온 진화 단계는 자동으로 도감에 남습니다.
15. **⛶ 전체 화면** — 상단의 **⛶**를 누르면 브라우저 주소창과 위·아래 작업 표시줄까지 사라져 화면을 가장 넓게 씁니다(아이 잠금 화면에서도 보입니다). 다시 누르거나 **ESC**로 돌아오고, 버튼 색과 설명이 지금 상태를 따라 바뀝니다. 전체 화면을 지원하지 않는 브라우저(iOS Safari 등)에서는 누를 때 `브라우저 메뉴의 '홈 화면에 추가'로 전체 화면을 쓸 수 있어요` 안내가 뜹니다. 홈 화면에 추가해 설치한 앱은 매니페스트가 `display: fullscreen`(차선 `standalone` → `minimal-ui` → `browser`)이라 열 때부터 전체 화면으로 뜨고, 이미 그 상태면 ⛶ 버튼은 숨겨집니다.
17. **🔔 알람** — 화면이 켜져 있는 동안 스스로 울립니다. 오늘 아직 안 끝낸 미션은 **마감 5분 전과 정각**, 오늘 가족 일정·구글 캘린더 일정(시각이 있는 것)은 **10분 전과 정각**에 화면 가운데 알람 창과 차임벨이 나옵니다. 맞춤 알람은 ⚙️ 설정 → **🔔 알람**에서 보호자가 시간·제목·요일을 정해 추가하고 켜고 끕니다(처음에는 **밥 먹기 끝 07:15 · 준비 끝 08:05**, 월~금). 같은 시각에 여러 알람이 겹치면 한 창에 나란히 보여 주고 소리는 한 번만 울립니다. 상단 **🔔 알람 소리** 버튼은 아이 잠금 화면에서도 보이며, 브라우저가 소리를 허락하도록 첫 한 번의 터치를 받습니다(그 전에는 버튼에 `1번 터치` 배지). 대기화면에서도 알람 창은 그대로 뜨고, `확인`을 누르면 대기화면이 유지됩니다.
18. 저장 형식은 `v3`입니다. 이전 `v2` 데이터가 있는 브라우저에서는 아이 누적 포인트를 현재 파트너 경험치로 옮겨 안전하게 마이그레이션됩니다.

## 개인정보

- 저장소에는 **어떤 개인정보도 들어 있지 않습니다.** 이름·주소·전화번호·실제 일정·실제 금액은 코드에 하드코딩되어 있지 않고, 기본값은 모두 중립적인 예시입니다.
- 기본은 **이 기기의 브라우저에만** 저장되며 서버로 전송되지 않습니다. 저장소를 내려받은 사람도 다른 사람의 기록을 볼 수 없습니다.
- **☁️ 로그인한 경우에만**, 기록이 가족의 비공개 Firebase(Firestore) 프로젝트로 전송됩니다. 계정 구분은 서버의 Custom Claims(`role`)로만 하고, 가족 이메일 목록·서비스 계정 키는 공개 저장소에도, 브라우저 코드에도 넣지 않습니다.
- **부모 모드 PIN**도 공개 코드에는 기본값 `0000`만 있습니다. 로그인 중 설정한 실제 PIN은 부모만 읽고 쓸 수 있는 비공개 Firebase 문서에 동기화되고, 기기별 localStorage에도 저장됩니다. 가족 이름·생신 같은 내용 역시 코드가 아닌 DB에만 있습니다.
- Firestore 보안 규칙이 서버에서 직접 검증합니다 — 가족 권한(`role: parent`/`child`)이 없는 계정은 읽기 자체가 거부되고, 수정할 때는 만든 사람·만든 시각을 바꿀 수 없습니다.
- 네트워크로 나가는 것은 날씨 조회(Open-Meteo), 포켓몬 그림(PokeAPI 이미지 저장소, `raw.githubusercontent.com`), 그리고 로그인·기록 동기화(Firebase)뿐입니다. 위치 좌표는 날씨를 받아오는 데만 쓰입니다.
- 포켓몬 그림은 [PokeAPI/sprites](https://github.com/PokeAPI/sprites)의 공식 일러스트(official-artwork, 475×475 PNG)를 불러옵니다. 화질 손상 없이 크게 보여 주기 위해 움직임은 CSS 애니메이션으로 만들고, 그림을 못 받으면 로컬에서 만든 SVG로 자동 대체됩니다. 포켓몬 이름·타입·진화 계열은 PokeAPI의 한국어 데이터를 코드에 옮겨 적은 것이라 개인정보가 아닙니다.

## 동기화 참고(코드 기준)

- **동시에 고칠 때**: 설정·가족 정보처럼 문서 하나를 통째로 올리는 항목(부모 기기의 '올리기')은 마지막에 저장한 쪽이 이전 값을 덮어씁니다. 부모 기기 두 대에서 같은 설정을 동시에 바꾸지 마세요. 아이의 미션 완료 기록은 미션별로 따로 쌓이므로 서로 덮어쓰지 않습니다.
- **오프라인**: 인터넷이 끊기면 화면은 그대로 동작하고, 기록은 연결이 돌아오면 자동으로 다시 보냅니다("연결이 잠시 끊겼어요" 카드).
- **자정**: 날짜가 바뀐 뒤에는 어제 미션을 아이 기기에서 기록할 수 없습니다. "날짜가 바뀌었어요" 카드가 뜨면 부모 기기에서 기록해 주세요.
- **앱 버전**: `app.js`의 `APP_VERSION` 한 곳에서 정하고, 화면 오른쪽 아래 표시와 `window.FamilyDashboard.version`이 같은 값을 읽습니다.

## 로컬 Firebase 에뮬레이터 검증

Node.js 20 이상과 Java가 필요합니다. `npm install` 후 `npm run check`와 `npm run test:unit`으로 문법 및 로컬 런타임 설정을 확인하고, `npm run test:emulator`로 Auth·Firestore 에뮬레이터에서 권한·미션 기록·정산을 검사합니다. Firebase CLI가 테스트 과정에서 에뮬레이터 파일을 내려받을 수 있습니다.

에뮬레이터는 `demo-family-dashboard`라는 별도 demo project ID와 loopback 주소(127.0.0.1)만 사용합니다. 운영 설정은 `boy7902-code.github.io`에서만 선택되고, 임시 미리보기·포워딩 호스트에서는 Firebase를 초기화하지 않습니다. 이 검사는 실제 Firebase 프로젝트, 배포된 보안 규칙, Google OAuth 팝업, 기존 가족 데이터 이관을 대상으로 하지 않습니다. 공개 전에는 Google 로그인 승인 도메인, 신뢰할 수 있는 역할(Custom Claims) 부여 절차, 실제 Firestore 규칙 배포 상태, 기존 Apps Script 기록의 이관·종료 계획을 별도로 검토해야 합니다.


## 연속 달성 기록 (기록 시작 이후만)

- 과거 미션 목록은 추정하지 않습니다. 보호자 계정이 연결되고 데이터가 모두 로드된 날부터 그날의 아이 미션 ID를 한 번 기록합니다.
- 기록 경로는 기존 부모 쓰기/가족 읽기 범위의 `child_state/mission_streak`입니다. 규칙 게시나 포인트 계산 변경은 없습니다.
- 그날 처음 기록한 대상 미션을 전부 완료하면 1일입니다. 일요일은 보호자 접속이 없어도 달력상 건너뜁니다(기록이나 완료를 만들지는 않음). 다른 요일의 대상 미션 없는 날은 그날 보호자 연결로 확인된 경우에만 건너뜁니다. 오늘 미완료는 자정까지 기다리고, 지난 날 미완료 또는 관찰 기록이 없는 날은 확인된 연속 기록을 끊습니다.
- 연속 기록의 날짜는 기기 시간대와 관계없이 한국 시간(KST)을 사용합니다.
- 당일 미션 추가·삭제·요일 변경은 이미 찍힌 대상 목록을 바꾸지 않습니다. 다음 날 새 목록에 반영됩니다. 따라서 미션 삭제만으로 과거 연속 달성이 부풀려지지 않습니다. 오늘 고정 대상인 미션을 삭제하면 오늘 연속 달성을 마칠 수 없으므로 두 삭제 경로 모두 영향 안내와 취소 기회를 제공합니다. 고정 대상이 아닌 미션·건너뛰는 날·완료 로그가 남는 경우에는 이 경고를 띄우지 않습니다.
- 완료 여부는 부모 기기의 트랜잭션에서 해당 날짜·미션의 실제 서버 로그를 읽습니다. 당일 취소는 반영하며, 지난 날은 다음 연결 때 최종 확인한 뒤 고정합니다. 오래된 날도 현재 미션 구성으로 다시 계산하지 않습니다.
- 최근 120개 관찰 날짜를 보관합니다. 화면에 시작 날짜를 표시하고, 기록 설명은 연속 표시를 누르면 볼 수 있습니다. 아이 기기만 켜져 있고 보호자 기기가 하루도 연결되지 않은 날은 대상 목록을 알 수 없으므로 소급해서 채우지 않습니다.
- 이 표시는 점수를 지급하지 않습니다. 기존 조기 보너스, 도장판, 콤보 및 저장된 포인트는 그대로입니다.

## 옛 동기화와 학교 카드

- Apps Script 동기화의 자동 복원·수동 연결·네트워크 전송 코드는 제거했습니다. 옛 저장값은 자동 삭제하거나 보내지 않습니다. 설정의 저장 정보 지우기 버튼은 사용자가 직접 눌렀을 때만 그 연결 정보를 지웁니다. 현재 Firebase 연결과 기기 내 데이터는 유지합니다.
- 학교의 급식·시간표 칩은 모두 표시합니다. `+N개` 접기 없이 카드 안을 스크롤해 마지막 항목까지 볼 수 있고, 태블릿의 96px 카드 높이는 유지합니다.
- 부모 PIN 안내·설정·잠금 동작은 이번 정리에서 제외했습니다.


## 공식 공휴일
한국천문연구원 특일 정보의 공휴일 조회를 사용합니다. 토요일에만 자유의 날 안내가 뜨며, 연속달성은 토·일·공식 공휴일을 건너뜁니다. 완료기록과 점수는 변하지 않습니다. 달력 날짜를 고르면 공휴일 이름을 볼 수 있습니다. 학교 재량휴업일은 포함하지 않습니다.
매일 한국시간 오전 6시대 GitHub Actions로 당해·다음해 공휴일을 조회하고 배포합니다. 실패하면 마지막 정상 파일을 유지합니다. 임시공휴일은 공식 API에 반영된 뒤 다음 정상 갱신부터 적용됩니다. 인증키는 KASI_SERVICE_KEY 저장소 비밀값에만 둡니다. 사이트로 전달되지 않습니다.

## 획득 자동반영 · 사용만 부모 정산
미션 완료는 고유한 날짜·미션·구성원 기록 한 개로 저장되고 별도 승인 없이 경험치·모은포인트에 반영됩니다. 도장10개당3P도 완료기록에서 자동 계산됩니다. 새로고침·다른 기기·상자 재열기로 추가 지급되지 않습니다. 오늘 미션을 취소하면 해당 포인트와 도장도 되돌아가며 재완료는 한 번만 반영됩니다. 기존 확정기록은 그대로 보존됩니다.
사용은 보호자 계정+PIN을 연 뒤 사용내용과 금액을 확인하여 정산합니다. 잔액만 차감되고 경험치는 줄지 않습니다. 기존 미션 일괄정산 기능은 작동하지 않습니다. 서버의 기존 settled:false 필드는 승인 대기가 아니라 호환용 원장구분이며 완료기록은 월이 지나도 합계에 포함됩니다. 보안규칙·계정권한·기존기록은 이 변경으로 바꾸지 않습니다.

### 미션 연속별과 보드 시간
- 아이 미션마다 별 다섯 조각을 모읍니다. 등록된 요일 중 평일 완료만 세고 토요일, 일요일, 공식 공휴일은 건너뜁니다. 해당 날짜의 미션은 보드 자정까지 완료할 수 있습니다.
- 다섯 번째 완료 때 해당 다섯 기록의 실제 적립 합계 30%를 반올림해 자동 합산하고, 별은 즉시 비웁니다. 완료 기록을 중복 구독해도 한 번만 합산합니다. 도입 전 기록은 소급 보상하지 않습니다.
- 보호자 연결 시 연속별 일정 기록을 시작합니다. 요일 변경은 다음 보드 날짜부터 적용해 과거 일정을 다시 쓰지 않습니다. 공휴일 자료가 없는 연도는 연속별 계산을 보류합니다.
- 미션 추가와 수정의 '시간 보너스'에서 사용 여부와 기준 시각을 정합니다. 기존 5~9분 전 +1P, 10분 이상 전 +2P는 그대로입니다. 기준 시각 이후에도 미션 완료, 기본 적립, 연속별 기록이 가능합니다.
- 표시 시각과 미션 완료 시각, 알람, 날짜 전환은 모두 실제 시각보다 5분 빠른 보드 시각을 씁니다. 서버도 동일한 고정 오프셋을 적용하고 기존 15분 기록 지연창을 유지합니다. 저장 생성시각은 실제 서버 시각을 유지합니다. 카운트다운, 잠금 만료, 인증 만료 등 경과시간은 실제 시간입니다.
